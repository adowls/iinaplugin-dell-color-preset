Display profiles (JSON)

Edit the complete profiles document. Save changes, then fully quit and restart IINA to apply them. A profile with verified: true may be used for automatic DDC writes.

Black out hotkey (mpv key binding format)

Toggles Black Out Other Monitors from the plugin menu. Works while IINA is the active app. Use a modifier plus one character, e.g. Alt+Shift+b, Ctrl+Alt+b, Cmd+Shift+b. Changes apply within a few seconds; clear the field to restore the default Alt+Shift+b. Combinations with Shift may be captured by an active CJK input method — prefer Ctrl+Alt+… in that case.
